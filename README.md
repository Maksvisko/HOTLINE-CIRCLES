# Hotline Circles

Неоновый 2D top-down шутер на **JavaScript + Canvas 2D**. Python нужен только
для необязательного десктопного окна. Ветка переработки: одна кампания от обучения до Big Bob,
обновлённая расстановка и эффекты стрельбы. Это ещё не готовый релиз.

## Игра по ссылке (GitHub Pages)

Адрес публикации: <https://maksvisko.github.io/HOTLINE-CIRCLES/>.
Ссылка становится рабочей после первого успешного развёртывания, а не просто
после включения Pages в настройках.

В **Settings → Pages → Build and deployment → Source** должно быть выбрано
**GitHub Actions**. Workflow `.github/workflows/pages.yml` проверяет проект и
публикует игру после обновления `main`. Также его можно запустить вручную через
**Actions → Publish game to GitHub Pages → Run workflow**, выбрав ветку `main`.
Сначала файл workflow должен попасть в `main` через pull request.

В разделе Actions дождитесь успешного завершения задания `deploy`. При ошибке
смотрите его лог: workflow `Project checks` сам по себе сайт не публикует.
В сайт попадают только `index.html`, JS-модули и стили из `src/` и доступные
MP3 из `audio/`; архивы, Python-код и диагностические отчёты не публикуются.

## Запуск

**Быстро:** откройте `index.html` в современном настольном браузере.
Сборка, npm и подключение к CDN не нужны.

**Для разработки:** из корня репозитория запустите:

```bash
python -m http.server 8000 --bind 0.0.0.0
```

Затем откройте <http://localhost:8000>. В Arena используйте окно Live Preview.
Сервер предназначен для локальной разработки, не для публичного хостинга.

**Музыка не приложена.** Положите свои треки в `audio/1.mp3` … `audio/6.mp3`;
назначения перечислены в [audio/README.md](audio/README.md). Без них возможны
сетевые 404 в консоли, но отказ `play()` обрабатывается и не прерывает игру.

### Отдельное десктопное окно (необязательно)

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux / macOS: source .venv/bin/activate
pip install -r requirements.txt
python game.py
```

На Windows необходим WebView2, на Linux — системный backend для pywebview
(GTK/WebKit либо Qt). Запуск GUI и сборка exe в текущей среде не проверены.
Путь к игре теперь определяется относительно `game.py`, а не рабочей папки.

Пример упаковки с современным PyInstaller (запускать из корня проекта):

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name HotlineCircles --add-data "index.html:." --add-data "src:src" --add-data "audio:audio" game.py
```

Сборку для Windows нужно выполнять на Windows. Один `--onefile` **не добавляет**
HTML, JS, CSS и музыку автоматически; поэтому ресурсы указаны явно.

## Что уже есть в исходниках

- Одна страница кампании: обучение → склад → офис → завод → штаб → Big Bob.
- Пять персонажей, включая секретного Поджигателя; оружие, способности и разные враги.
- Самостоятельные планировки склада, завода и штаба; офис пока сохраняет старую геометрию.
- Случайные препятствия с проверкой проходов, безопасные появления, сеточная навигация.
- Повторяемая расстановка при рестарте, раннее оружие на боевых уровнях.
- Следы пуль, вспышки ствола, искры и реакция на попадания.
- HARD-MODE, пауза, перезапуск, RU/EN, громкость и вписывание игрового экрана в окно.

Вторая глава удалена из рабочей версии; оригиналы остались в `archive/`.
Сохранений пока нет. Полное прохождение и баланс переработанных карт ещё требуют
ручной проверки. Подробности изменений — [docs/REWORK.md](docs/REWORK.md).

## Управление

| Кнопка | Действие |
|---|---|
| WASD / ЦФЫВ | Движение |
| Мышь | Прицеливание |
| ЛКМ | Стрельба / атака |
| ПКМ | Способность персонажа |
| E / У | Подобрать оружие / топливо |
| Пробел | Вернуться к стартовому оружию персонажа |
| Esc | Пауза / продолжить |

## Как теперь всё разложено

```text
index.html                   разметка интерфейса, canvas и подключения
src/game.js                  игровая сессия, UI, бой и рендер
src/levels.js                кампания, планировки и генерация препятствий
src/world.js                 геометрия, навигация и безопасный спавн
src/effects.js               следы снарядов и эффекты попаданий
src/styles.css               стили и локальные замены трёх Tailwind-утилит
game.py                     необязательная оболочка pywebview
audio/                      место для музыки и инструкция
archive/originals/          неизменённые исходные вложения
archive/build-reports/      старые диагностические отчёты PyInstaller
archive/manifest.json       размеры и SHA-256 всех 9 доступных вложений
docs/AUDIT.md               сравнение версий, устройство и технические риски
docs/ROADMAP.md             приоритеты и критерии готовности следующих работ
docs/TESTING.md             проверки и ручной чек-лист
docs/REWORK.md              описание текущей переработки
tools/check_project.py      проверки целостности и связей исходников
tests/                      игровые регрессии, браузерный smoke и тесты оболочки
.github/workflows/          автоматические проверки push / pull request
```

Исходные HTML сохранены целиком и проверяются по SHA-256. Рабочий код уже
изменяется; проверки буквального равенства JS/CSS оригиналу заменены игровыми
регрессиями. Сборщик и внешние runtime-зависимости не добавлены.

## Проверки

Нужны Python 3.10+ и Node.js (в CI: Python 3.11 / Node 22). Установка пакетов не нужна:

```bash
python tools/check_project.py
python -m unittest discover -s tests -v
```

Добавлены 15 игровых тестов Node, проверки структуры проекта и путей оболочки.
Выполнен smoke-тест в настоящем Chromium; это **не полный тест прохождения игры**. Подробности — [docs/TESTING.md](docs/TESTING.md).
