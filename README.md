# Hotline Circles

Неоновый 2D top-down шутер на **JavaScript + Canvas 2D**. Python нужен только
для необязательного десктопного окна. Это восстановленная основа из присланных
версий, а не новая игра и не готовый релиз.

## Запуск

**Быстро:** откройте `index.html` в современном настольном браузере.
Сборка, npm и подключение к CDN не нужны.

**Для разработки:** из корня репозитория запустите:

```bash
python -m http.server 8000 --bind 0.0.0.0
```

Затем откройте <http://localhost:8000>. В Arena используйте окно Live Preview.
Сервер предназначен для локальной разработки, не для публичного хостинга.

**Музыка не приложена.** Положите свои треки в `audio/1.mp3` … `audio/6.mp3`;
назначения перечислены в [audio/README.md](audio/README.md). Без них возможны
404 и ошибки `play()` в консоли: обработка отсутствующих треков ещё требует
исправления. Музыка главы 2 пока не назначена.

### Отдельное десктопное окно (необязательно)

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux / macOS: source .venv/bin/activate
pip install -r requirements.txt
python game.py
```

На Windows необходим WebView2, на Linux — системный backend для pywebview
(GTK/WebKit либо Qt). Запуск GUI и сборка exe в текущей среде не проверены.
Путь к игре теперь определяется относительно `game.py`, а не рабочей папки.

Пример упаковки с современным PyInstaller (запускать из корня проекта):

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name HotlineCircles --add-data "index.html:." --add-data "src:src" --add-data "audio:audio" game.py
```

Сборку для Windows нужно выполнять на Windows. Один `--onefile` **не добавляет**
HTML, JS, CSS и музыку автоматически; поэтому ресурсы указаны явно.

## Что уже есть в исходниках

- Глава 1: обучение и уровни 1–5 — склад, офис, завод, штаб, Big Bob.
- Глава 2: HoTRoD с Jack и Skyward Ascent со Skyler; есть заглушка будущего уровня.
- Пять персонажей главы 1, включая секретного Поджигателя; два сюжетных героя главы 2.
- Оружие, способности, враги, боссы, взрывные бочки, гранаты, рывок, кат-сцена.
- HARD-MODE, пауза, перезапуск, настройки RU/EN, громкости и размера canvas.

Наличие кода не означает, что каждый сценарий полностью протестирован.
Сохранений пока нет; масштабирование и переходы между режимами требуют проверки.

## Управление

| Кнопка | Действие |
|---|---|
| WASD / ЦФЫВ | Движение |
| Мышь | Прицеливание |
| ЛКМ | Стрельба / атака |
| ПКМ | Способность персонажа |
| E / У | Подобрать оружие / пропустить кат-сцену HoTRoD |
| Пробел | Вернуться к стартовому оружию персонажа |
| Esc | Пауза / продолжить |

## Как теперь всё разложено

```text
index.html                   разметка интерфейса, canvas и подключения
src/game.js                  исходная игровая логика, пока одним файлом
src/styles.css               стили и локальные замены трёх Tailwind-утилит

 archive/build-reports/      старые диагностические отчёты PyInstaller
 archive/manifest.json       размеры и SHA-256 всех 9 доступных вложений
 docs/AUDIT.md               сравнение версий, устройство и технические риски
 docs/ROADMAP.md             приоритеты и критерии готовности следующих работ
 docs/TESTING.md             проверки и ручной чек-лист
 tools/check_project.py      проверки целостности и связей исходников
 tests/                      тесты путей десктопной оболочки
 .github/workflows/          автоматические проверки push / pull request
```

Исходные HTML сохранены целиком. Рабочий `index.html` выбран из более полной
ветки на 6069 строк; `src/game.js` извлечён без изменения логики. Внешний Tailwind
убран, три используемые HUD-утилиты добавлены локально. Глубокое разделение JS на
подсистемы намеренно отложено до стабилизации поведения.

## Проверки

Нужны Python 3.10+ и Node.js (в CI: Python 3.11 / Node 22). Установка пакетов не нужна:

```bash
python tools/check_project.py
python -m unittest discover -s tests -v
```

Сейчас проходят 10 автоматических проверок. Это проверки исходников и путей,
**не полный тест прохождения игры**. Подробности — [docs/TESTING.md](docs/TESTING.md).

## Дальнейшая работа

Начать с [плана](docs/ROADMAP.md): переходы состояний и сброс ввода → масштабирование
и таймеры → сохранения → постепенная модульность → контент и релизы.
Перенос на другой движок пока не требуется.

Лицензия проекта и права на будущие аудиотреки пока не определены. Перед публичным
релизом нужно отдельно согласовать лицензию и происхождение ресурсов.
