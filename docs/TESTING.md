# Проверки

## Автоматически, без установки пакетов

Нужны Python 3.10+ и Node.js:

```bash
python tools/check_project.py
python -m unittest discover -s tests -v
```

Первый скрипт проверяет:

1. Размеры и SHA-256 всех 9 доступных исходных вложений.
2. Буквальное совпадение JS с извлечённым исходным блоком.
3. Сохранность исходного CSS и наличие локальных HUD-утилит.
4. Уникальность HTML ID.
5. Существование элементов для статических вызовов `getElementById`.
6. Наличие функций для inline-обработчиков HTML.
7. Локальные ссылки на ресурсы; отсутствие MP3 временно разрешено явно.
8. Синтаксис JavaScript через `node --check`.

Второй набор содержит два теста `resource_path`: запуск из другой рабочей папки
и поиск файлов внутри PyInstaller `_MEIPASS`. pywebview для тестов не нужен.

Оба набора включены в `.github/workflows/checks.yml` для push и pull request.
Локально все **10 проверок прошли**. Состояние workflow на GitHub не проверялось.

Проверки равенства JS/CSS — временная защита этапа импорта, не запрет на развитие.
При первом осознанном изменении соответствующей подсистемы заменить такую проверку
тестом её поведения. Архив и проверки его контрольных сумм при этом не менять.

## Ограничения

Эти проверки не исполняют игровую логику в настоящем браузере, не оценивают
визуальное оформление, производительность или достижимость победы.
Попытка headless Chromium в текущем окружении завершилась до старта браузера из-за
отсутствующего `libnspr4.so`. Запуск десктопной оболочки и сборка exe не проверены.

## Ручной чек-лист перед изменением механик

Запуск: `python -m http.server 8000 --bind 0.0.0.0`, затем открыть игру в браузере.
Все пункты ниже **пока не отмечены как пройденные**.

### Интерфейс

- [ ] Главное меню отображается без CDN / интернета; кнопки работают.
- [ ] Настройки открываются из меню и из паузы, возврат ведёт в правильный экран.
- [ ] Язык RU/EN, громкость и размеры canvas меняются без ошибок.
- [ ] Глава 1 ↔ глава 2, выбор персонажа и кнопки «Назад» не оставляют наложенных меню.
- [ ] Проверены окна 1280×720 и 1920×1080; кнопки и HUD доступны.
- [ ] Курсор совпадает с направлением стрельбы после изменения разрешения.

### Сессия и ввод

- [ ] WASD и русская раскладка работают; Esc ставит на паузу и продолжает.
- [ ] ЛКМ стреляет, ПКМ активирует способность без лишнего выстрела.
- [ ] E подбирает оружие, пробел возвращает именно стартовое оружие героя.
- [ ] Отпускание мыши за пределами canvas прекращает стрельбу.
- [ ] Alt-Tab и потеря фокуса не оставляют нажатые клавиши.
- [ ] Пауза останавливает бой, эффекты и связанные с боем таймеры.
- [ ] Смерть → рестарт и выход → новый забег полностью сбрасывают состояние.
- [ ] HARD-MODE → отмена / выход → обычная игра не сохраняют флаг hard-mode.

### Контент

- [ ] Обучение пройдено каждым из пяти героев главы 1.
- [ ] Уровни 1–4 и Big Bob пройдены; смерть и победа открывают правильные экраны.
- [ ] HARD-MODE последовательно проходит уровни 1–5 и корректно завершается.
- [ ] HoTRoD: кат-сцена, пропуск по E, гранаты, бочки и финальная волна.
- [ ] Skyward: рывок между крышами, границы, смерть / безопасный возврат и победа.
- [ ] Смена оружия не восстанавливает потраченные патроны, новый забег их сбрасывает.
- [ ] Боссы, снаряды и отложенные действия не переживают выход в другую сессию.

### Звук и упаковка

- [ ] Без MP3 игра остаётся доступной; отдельно зафиксировать ошибки загрузки/play().
- [ ] С собственными MP3: меню / уровни / босс, пауза и громкость работают.
- [ ] Запуск `game.py` из другой рабочей папки на целевой ОС.
- [ ] Собранное приложение открывается без установленных исходников и Python.

Для найденного бага записать последовательность шагов, браузер/ОС, ожидаемое
и фактическое поведение, сообщение консоли. Не отмечать проверенным то, что
подтверждено только чтением исходников.
