# Проверки

## Автоматические регрессии (без установки пакетов)

Требуются Python 3.10+ и Node.js 22:

```bash
python tools/check_project.py
python -m unittest discover -s tests -v
```

Первая команда запускает 9 проверок проекта, включая вложенный набор из
15 игровых тестов Node. Вторая — 2 теста путей десктопной оболочки.
Отдельный запуск только игровых тестов:

```bash
node --test tests/*.test.cjs
```

### Что проверяется

- SHA-256 и размеры всех 9 оригинальных вложений: архив не менялся.
- Одна страница выбора с уровнями 0–5, без второй главы, правильный порядок скриптов.
- Уникальные HTML ID, связи обработчиков, локальные ресурсы, синтаксис всех JS-файлов.
- Геометрия 6 уровней × 20 seed: связность навигации, безопасный старт, допустимый
  бюджет препятствий, зарезервированные проходы и безопасное появление тел радиуса 26.
- Повторяемость генерации; независимые планировки и сохранение геометрии офиса.
- Обход длинной стены без телепортации, скольжение вдоль стен, защита от пролёта
  быстрого тела сквозь тонкую стену, цель у стены.
- Пересечения отрезка с телами/стенами, явный отказ при отсутствии свободной позиции.
- Ограничение числа эффектов, время жизни и сброс.
- Реальные скрипты игры в VM с адаптером DOM/Canvas: 6 уровней × 5 персонажей,
  update/draw, стабильный рестарт, попадания, пробитие, мишени и босс.
- Пауза и сброс ввода, разделение ЛКМ/ПКМ, сброс HARD-MODE, появление/победа Шерифа.
- Пауза боевых таймеров, отмена при рестарте и защита от callback старой сессии.

VM не рисует настоящие пиксели. Это тест исполнения логики, не визуальный тест.
Проверки равенства рабочего JS/CSS исходным блокам заменены регрессиями поведения:
игра теперь развивается, а неизменность архива проверяется отдельно.

Все эти проверки входят в существующие CI workflows проверки и публикации Pages.

## Дополнительный smoke-тест в настоящем браузере

Запустить HTTP-сервер:

```bash
python -m http.server 8000 --bind 0.0.0.0
```

Для `tests/browser-smoke.cjs` отдельно нужны `playwright-core` и установленный
Chromium. Они не являются зависимостями самой игры. Например, в POSIX-оболочке:

```bash
npm install --prefix .cache/browser-tools --no-audit --no-fund playwright-core
NODE_PATH="$PWD/.cache/browser-tools/node_modules" \
CHROMIUM_EXECUTABLE="/path/to/chromium" \
GAME_URL="http://127.0.0.1:8000/" \
node tests/browser-smoke.cjs
```

На Windows задайте эти переменные средствами PowerShell и укажите путь к Chrome
или Chromium. Системные библиотеки браузера должны быть установлены отдельно.
`SCREENSHOT_PATH` необязателен: сохраняет кадр для локальной проверки.

**Выполнено в текущей среде:** Chromium с Playwright успешно проверил настоящий
маршрут меню → склад → персонаж → игра → пауза → настройки EN / разрешение →
продолжение; шесть уровней и рестарты; попадание, частицы и следы; отсутствие
второй главы и сброс HARD-MODE. Canvas помещается в окно 1280×720, координаты мыши
совпадают с виртуальным разрешением. Не было `pageerror` или внешних запросов.
Недостающие библиотеки прежней попытки удалось предоставить из временного
browser-tooling; в репозиторий они не добавлены.

## Что ещё не проверено полностью

- Полное прохождение обучения всеми персонажами и кампании, включая HARD-MODE.
- Субъективные ощущения стрельбы, баланс новых планировок и всех сочетаний врагов.
- Отсутствие любых застреваний: связность сетки и один маршрутный регрессионный
  сценарий не являются доказательством идеального поведения AI во всех ситуациях.
- Производительность на слабых ПК; при низком FPS симуляция всё ещё замедляется.
- Музыка с настоящими MP3: файлов нет. Обработка отказа `play()` проверена;
  браузер всё ещё может показывать сетевые 404 для отсутствующих треков.
- Запуск pywebview и сборка exe на целевых ОС.

## Ручной чек-лист перед релизом

- [ ] Пройти обучение всеми пятью персонажами, особенно танком и Поджигателем.
- [ ] Пройти склад, офис, завод, штаб с Шерифом и Big Bob.
- [ ] Пройти HARD-MODE от начала до конца; проверить смерть и выбор персонажа.
- [ ] Проверить точность прицела и доступность меню при разных размерах окна.
- [ ] Проверить смену оружия, боезапас, способности и подбор топлива.
- [ ] Увести всех типов врагов за углы и через проходы; записать застревания.
- [ ] Проверить реальные MP3, громкость, паузу, выключение звука.
- [ ] Проверить Windows-оболочку и упакованное приложение на чистом ПК.

Для найденной ошибки записать seed (в консоли `levelSeed`), уровень, персонажа,
действия, браузер/ОС и сообщение консоли. Один seed воспроизводит исходную
планировку; поведение врагов во времени пока не является полным deterministic replay.
