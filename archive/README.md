# Исторические материалы

`originals/` — все доступные исходные файлы игры и описания, без изменений.
`build-reports/` — диагностические результаты старой сборки PyInstaller,
не часть игры и не требования к установке зависимостей.

`manifest.json` содержит исходное имя, путь в архиве, размер и SHA-256 каждого
из 9 доступных вложений. Повторные имена из списка загрузок не были доступны
как отдельные файлы. Дубли с разными именами сохранены намеренно.

Архив не редактировать при доработке игры. Рабочие файлы находятся в корне
репозитория и `src/`. Отчёты содержат исторические локальные пути: перед
публичным распространением отдельно проверить приватность. Не включать архив
в дистрибутив игры.

Сравнение версий и выбор основы: [docs/AUDIT.md](../docs/AUDIT.md).
