# 🎮 Hotline Circles

2D-шутер **top-down** в неоновой эстетике Hotline Miami. Проект связан с вселенной
Hotline Miami: миамские локации, неон, синтвейв-саундтрек и жесткий боевой ритм.

## Что внутри

- **Глава 1** — 6 уровней: Учебное → Склад → Офис → Завод → Штаб → Босс (Big Bob).
- **Глава 2** — две новые истории:
  - **HoTRoD** — Джек (Jack / Mesh): два пистолета + гранаты, кат-сцена, взрывные
    бочки, финальный рэйд миниграннеров.
  - **Skyward Ascent** — Скайлер (Skyler): рывок (dash) по крышам днём.
- **Персонажи с умениями (ПКМ)**: Стандарт (ускоренная стрельба), Танк (щит),
  Стрелок (×2 боезапас + аптечка), Рубака (мачете), Поджигатель (секретный,
  огнемёт), Джек (гранаты), Скайлер (рывок).
- **Вражья система**: преследование, стрельба, стационарные турели (gunnest),
  мини-босс (Шериф), миниганеры, босс с полосой здоровья.
- **Меню**: выбор уровня/главы, выбор персонажа, настройки (язык RU/EN,
  размер окна, громкость), HARD-MODE, пауза, меню смерти.

## Как запустить

### В браузере (просто)
Откройте `index.html` в любом браузере.
> Примечание: стили используют Tailwind из CDN, поэтому для красивого вида
> нужно подключение к интернету (логика игры работает и без него).

### Десктоп-версия (pywebview)
```bash
pip install pywebview
python game.py
```
Окно открывает `index.html`. Для сборки в exe:
```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name HotlineCircles game.py
```
Сборку можно делать и в Windows — `game.py` уже учитывает путь к ресурсам
(`sys._MEIPASS`) для PyInstaller.

## Управление

| Кнопка | Действие |
|--------|----------|
| ЛКМ | Стрельба / атака оружием |
| ПКМ | Умение персонажа (зависит от персонажа) |
