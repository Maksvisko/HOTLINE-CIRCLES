# Музыка в игре

Игра подключает фоновую музыку из `index.html` по путям:

| Файл | Что играет |
|------|------------|
| `audio/1.mp3` | Меню |
| `audio/2.mp3` | Уровень 1 |
| `audio/3.mp3` | Уровень 2 |
| `audio/4.mp3` | Уровень 3 |
| `audio/5.mp3` | Уровень 4 |
| `audio/6.mp3` | Босс (уровень 5) |

**Как добавить:** скопируйте свои MP3-треки в эту папку под этими именами.
Если файла нет, игра просто не будет играть музыку — это не критичная ошибка.

Формат: MP3, 16-bit, 44.1 kHz (любой распространённый формат MP3 подойдет).
