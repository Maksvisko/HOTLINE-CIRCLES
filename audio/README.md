# Музыка

Аудиофайлы не были приложены. Здесь должны лежать ваши MP3-треки:

| Файл | Назначение |
|---|---|
| `1.mp3` | Главное меню |
| `2.mp3` | Уровень 1 — склад |
| `3.mp3` | Уровень 2 — офис |
| `4.mp3` | Уровень 3 — завод |
| `5.mp3` | Уровень 4 — штаб |
| `6.mp3` | Уровень 5 — Big Bob |

HTML обращается к ним по относительным путям `audio/1.mp3` … `audio/6.mp3`.
Для обучения (уровень 0) и главы 2 отдельные MP3 в текущем коде не назначены.
Обычного MP3 достаточно; требование «16-bit» к сжатому MP3 не применяется.

Без этих файлов саундтрек отсутствует. Игра не проверяет существование треков
заранее, а обработка Promise от `play()` пока неполная: возможны 404 и ошибки
консоли. Исправление запланировано в первом этапе стабилизации.

Добавляйте только треки, на использование и распространение которых у вас есть
права. Порядок хранения и публикации крупных аудиофайлов (обычный Git или Git LFS)
нужно выбрать после получения файлов и оценки их размера.
